# Sales Performance Dashboard (Excel)

## Project Overview

This project explores a 2025 sales dataset and presents key business performance measures in an interactive Microsoft Excel dashboard. The workbook includes the source sales records, supporting summary analyses, PivotTables, charts, and dashboard-level KPIs.

The project was completed as an independent learning and portfolio project while developing practical data analysis skills.

## Business Questions

The analysis is organised to help explore questions such as:

- What are the overall sales revenue, profit, order volume, and units sold?
- How do revenue and profit compare across regions?
- Which product categories contribute most to revenue and profit?
- How does revenue change across months?
- How do sales representatives compare by revenue?

## Tools and Excel Features

- Microsoft Excel
- Structured tables and formulas
- PivotTables for summarising sales data
- Charts for data visualisation
- Slicers for interactive filtering
- KPI cards for displaying headline performance measures

## Dataset

The workbook contains 600 sales records and fields covering sales transactions, products, regions, customers, quantities, prices, discounts, revenue, and profit.

## Analysis Included

- Revenue and profit by region
- Revenue and profit by product category
- Monthly revenue
- Revenue by sales representative
- Overall revenue, profit, order, and unit KPIs

## How to Use

1. Download `Sales_Performance_Dashboard.xlsx`.
2. Open it in Microsoft Excel.
3. Go to the dashboard worksheet.
4. Use the slicers, where available, to filter the dashboard and explore the results.
5. Review the supporting worksheets for the underlying summaries.
